# Headings

Follow these guidelines so that you can consistently use Markdown to format headings.

## Use #-style headings

- **keywords**: markdown, formatting, headings
- **content sets**: documentation, tutorials

Use `#` characters to create headings. Do not use underline-style (`===` or `---`) headings. Match the number of `#` characters to the heading level. For guidance on heading hierarchy and capitalization, refer to the titles and headings guidelines.

### Examples

**Do**

```
# Page title

## Section heading

### Subsection heading
```

**Don't**

```
Page title
==========

Section heading
---------------
```
